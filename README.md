# PixelNorte
Sitio web de PixelNorte que muestra los servicios de la empresa,
 información de contacto y página principal.

## Tecnologias
- HTML5
- CSS3 (Flexbox, Grid, Mobile First)

## Estructura
- `index.html` - pagina principal
- `servicios.html` - catalogo de servicios prestados
- `contacto.html` - formulario e informacion de contacto
- `style.css` - hoja de estilos general
- `img/` - carpeta con las imagenes del sitio
